## 中文

### 新功能：手機儀表板（不用裝 App）

電腦跑 LagScope，手機瀏覽器連進來就能看到**同一份即時數字**——iPhone、Android 都可以，
不用裝任何東西。適合「電腦在客廳、人在沙發」，或打遊戲時把手機擱旁邊當儀表板。

**怎麼開：**

1. 設定 → 常規 → **手機儀表板** → 勾「讓同一網路下的手機也能看」
2. 填一組存取碼（建議填，四位數就夠）
3. 下面會直接顯示網址，例如 `http://192.168.1.20:23125/?key=4321`
4. 手機連同一個 Wi-Fi，瀏覽器打開那個網址

托盤選單也多了「**手機網址…**」，會列出網址並自動複製到剪貼簿。

**畫面上有**：總延遲大字（依門檻綠／黃／紅）、分項（跟著監測模式變）、折線圖、
均值／P95／上下行、抖動與卡頓次數，每 2 秒自動更新；連不上時會明確告訴你可能的原因。

**安全性：**

- 預設**關閉**，要自己打開才會開埠。
- **唯讀**：整個服務只有兩個 GET 端點，手機上改不了任何設定，也控制不了監視器。
- 只在你的**區域網路**內有效；填了存取碼後，沒帶碼就是 403。
- 網頁**完全自包含**，不載入任何外部資源，沒有網際網路的區網也能開。

### 為什麼不是手機版 App

兩個硬限制：Android 10 起不讓 App 讀別的程式的連線表（要 root 或做成 VPN 服務），
iOS 完全不允許任何 App 浮在別的 App 上面。所以「任意 App 延遲」和「懸浮窗」這兩個核心功能
在手機上做不到，手機這邊的定位是**看電腦量到的數字**。

## English

### New: a phone dashboard, with nothing to install

Run LagScope on the PC and open one address in a phone browser: the same live numbers, on iPhone
and Android alike. Useful when the machine is across the room, or when the game is on it and the
phone can sit beside the keyboard as a second screen.

**Turning it on:** Settings → General → **Phone dashboard**, optionally set an access code, then
open the address it shows (also available from the tray menu, which copies it for you).

The page shows the total with its colour band, the per-mode breakdown, a sparkline, avg / p95 /
up / down, jitter and the stall count, refreshing every two seconds - and says what is wrong when
it cannot reach the monitor.

**Deliberately narrow:** off by default, LAN only, optional access code, and **read-only** - two
GET endpoints, with no way to change a setting or control the monitor from the phone. The page is
fully self-contained, so it renders on a network with no internet at all.

### Why not a phone app

Since Android 10 an app cannot read another app's connection table without root or a VPN service,
and iOS allows no overlay over other apps at all - so the two features that matter most cannot
exist there. The phone shows what the PC measures.
