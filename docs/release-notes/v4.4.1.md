> 修掉 v4.4 剛發布時的一個當機：**程式一開起來就馬上按「測一下網速…」會讓背景執行緒掛掉。**
> v4.4 的功能說明看[這裡](https://github.com/cxu4425-beep/LagScope/releases/tag/v4.4)。
>
> Fixes a crash in v4.4: running the new speed test before the first probe cycle.

## 中文

托盤選單的「測一下網速…」隨時都能按，但底層的 HTTP 連線是**第一次探測**的時候才建立的。
所以在下面這兩種情況按下去，背景執行緒會直接掛掉（畫面沒反應，也不會跳錯誤）：

- 程式剛開起來、還沒跑完第一輪探測就馬上按；
- 監測是停著的時候按。

現在它會自己把連線建起來，跟探測那條路徑本來的做法一樣。

順帶一提這個 bug 是**寫測試的時候自己抓到的**，不是使用者回報的——但它是在 v4.4 打包出去
之後才發現的，所以補一個 v4.4.1。新增的那個測試會在沒有修正的情況下直接紅掉。

## English

The tray item is available at any time, but the HTTP client it needs is built by the first
probe cycle. Running a speed test straight after launch, or while monitoring is stopped, put
an `AssertionError` on the worker thread - no error dialog, just nothing happening. It now
builds the client itself, exactly as the probe path already did.

Found while writing tests rather than by a user, but found after v4.4 had shipped. The
accompanying test fails without the fix.
