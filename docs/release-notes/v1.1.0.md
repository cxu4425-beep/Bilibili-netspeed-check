## 中文

這一版最大的改變：**不再只能量 B 站**。

### 任何程式都能測

- **任意應用程序模式**：選一個程式（遊戲、通話、瀏覽器、下載器…），監視器從系統連線表找出
  **它實際連的伺服器**，每輪對最忙的那個公網位址計時。UDP 的遊戲連不上 TCP 時自動改用系統
  `ping`（不需要管理員權限）。懸浮窗顯示 **延遲 / 連接數 / 顯示**。
- **自動跟隨前景程式**：切到哪個視窗就量哪個程式。
- **自訂伺服器位址**：直接填遊戲伺服器、公司 VPN、`8.8.8.8`，先試 TCP、不通就 ping。
- **全機上傳／下載速度**：每筆樣本都附帶，一眼看出是不是有別的東西在吃頻寬。
- **卡頓／延遲突增偵測**：探測失敗記一次卡頓（連續失敗只記一次），延遲跳到近期中位數兩倍記一次
  突增；突增不列入中位數，免得一次抽風把基準帶歪。保留一小時，可彈出提示（有冷卻時間）。

### B 站功能加厚

- **CDN 線路比較**：同一個直播間 B 站會發好幾個節點，每 2 分鐘全部測一遍，
  診斷資訊會顯示目前這條與最快那條的差距。
- **直播間詳情**：人氣、分區、開播時長、畫質名稱、編碼、格式。
- 診斷資訊（托盤選單 →「複製診斷信息」）現在還包含事件統計、網速與線路清單。

### 新的命令列參數

```
--app 程式名稱        量某個程式的延遲
--app-foreground      量目前最前面那個程式
--ping 位址           量某個位址（--ping-port 指定連接埠）
--list-apps           列出正在連網的程式
```

### 修正

- 命令列的「這一輪要量什麼」判斷與 GUI 各寫一份且已過時，導致 `--app` / `--ping` 被忽略；
  兩邊現在共用同一個解析器，並有測試把它們釘在一起。
- 自動偵測的掃描節流用 `0.0` 當哨兵與 `monotonic()` 相比，開機未滿 5 分鐘的電腦會跳過第一次掃描。
- macOS 打包時傳 `.png` 當圖示可能導致建置失敗，現在只有 Windows 會內嵌圖示。

### 升級注意

新增執行階段依賴 **psutil**（從原始碼跑的人請重新 `pip install -r requirements.txt`；
下載 exe 的人不受影響）。設定檔會自動沿用，不需要重設。

## English

The headline change: **it is no longer Bilibili-only.**

### Any application

- **Any-application mode**: pick a process (a game, a voice app, a browser, a downloader) and the
  monitor reads the system connection table to find **the servers it is actually talking to**,
  timing the busiest public endpoint each round. UDP servers never answer a TCP handshake, so
  those fall back to the system `ping` - no administrator rights needed.
- **Follow the foreground app**: whatever window you switch to is what gets measured.
- **A server address you type**: a game server, a VPN gateway, `8.8.8.8`.
- **Machine upload / download speed** on every sample.
- **Stall and spike detection**, with one rate-limited notification rather than one per sample.

### Bilibili, deeper

- **CDN line comparison** - every edge the room is offered on is timed periodically, and the
  diagnostics show the current one against the best.
- **Room details**: popularity, category, uptime, quality name, codec, container.

### New command line flags

`--app`, `--app-foreground`, `--ping` / `--ping-port`, `--list-apps`.

### Fixes

- The CLI had its own stale copy of the "what am I measuring" rule, which silently ignored
  `--app` and `--ping`; both paths now share one resolver, pinned by a test.
- Auto-detection skipped its first scan on a machine that had been up for less than the poll
  interval (a `0.0` sentinel compared against `monotonic()`).
- Passing a `.png` as the macOS bundle icon could fail that build.

### Upgrading

**psutil** is a new runtime dependency - re-run `pip install -r requirements.txt` if you run from
source. Downloaded executables already include it. Existing settings carry over unchanged.
