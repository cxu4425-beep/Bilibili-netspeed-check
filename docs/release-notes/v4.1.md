## 中文

### 🌏 介面加入日文與韓文

`简体中文 / 繁體中文 / English / 日本語 / 한국어`——五種語言，預設跟隨系統，
也可以在**初次設定精靈**或**設定 → 常規 → 界面語言**隨時改。

翻譯是**全介面**的：懸浮窗、托盤、設定、精靈、歷史視窗、體檢報告（HTML 和純文字兩版）、
命令列輸出、全部 8 種診斷結論，一共 278 條字串，日韓各翻了 278 條，沒有漏掉的。

`--lang` 也接受新語言：

```bash
lagscope --lang ja
lagscope --lang ko
```

系統語言是 `ja_JP` 或 `ko_KR` 的話，第一次開啟就會是對應語言，不用手動選。

### 🧱 順手修掉的一個排版 bug

翻成日文之後，設定精靈裡的說明文字**被切掉了一半**。

原因是 Qt 的 `QLabel` 開了自動換行之後，要先知道寬度才算得出高度，而垂直排版預設不會去問，
所以第二行直接被裁掉。中文版剛好每句都只有一行，所以這個問題**藏了三個版本沒被發現**——
一翻成需要兩行的語言就立刻現形。

現在所有換行的說明文字都會正確要到高度，而且會**預留最高的那種情況**，
所以點不同選項切換說明時視窗也不會忽大忽小。

### 其他

- Windows 安裝程式也加上日文和韓文介面（和中文一樣，編譯器有語言檔就用、沒有就退回英文）。
- 報告的純文字版對齊是按**顯示寬度**算的，所以日文和韓文的表格一樣不會歪。

## 日本語

### 日本語に対応しました

表示言語に **日本語** が加わりました。`简体中文 / 繁體中文 / English / 日本語 / 한국어` の
5 言語から選べます。既定ではシステムの言語に従うので、`ja_JP` の環境なら初回起動から
日本語で表示されます。設定でいつでも変更できます。

翻訳は全画面が対象です——オーバーレイ、トレイ、設定、初期設定、履歴ウィンドウ、
診断レポート（HTML とテキストの両方）、コマンドラインの出力、8 種類すべての診断結論。
278 個の文字列を一つ残らず翻訳しました。

コマンドラインは `lagscope --lang ja` です。

### レイアウトの不具合をひとつ修正

日本語にしたところ、初期設定ウィザードの説明文が途中で切れていました。折り返しを有効にした
`QLabel` は幅が決まらないと高さが分からず、縦方向のレイアウトは既定でそれを尋ねないため、
2 行目が切り捨てられていたものです。中国語では偶然どの説明も 1 行に収まっていたので、
3 バージョンにわたって気づかれませんでした。修正済みです。

명령줄은 `lagscope --lang ko` 입니다.

## English

### Japanese and Korean

Five interface languages now: `简体中文 / 繁體中文 / English / 日本語 / 한국어`. The default
still follows the system, so a `ja_JP` or `ko_KR` machine comes up translated on first run, and
`--lang ja` / `--lang ko` work on the command line.

Both are complete rather than partial: all 278 strings, covering the overlay, tray, settings,
wizard, history window, the report in both HTML and plain text, the command line output and
every one of the eight diagnosis verdicts. A test asserts the coverage and that every `{value}`
placeholder survived translation, so a half-finished language cannot ship by accident.

Structurally the two new languages are dictionaries layered over the existing three-column
table rather than two more columns in it. Widening 278 tuples would have meant every future
string had to be written five times before the app would start; an overlay that falls back to
English means a missing string is a blemish, not a crash.

### A layout bug it flushed out

Translating the wizard immediately clipped its hint text. A word-wrapped `QLabel` only knows
its height once it knows its width, and a box layout does not ask unless the size policy says
to - so the second line was simply cut off. Every hint happened to fit on one line in Chinese,
which is why this survived three releases unnoticed. Wrapped labels now get the height they
ask for, and reserve the tallest case so the dialog does not resize as you click through the
options.

### Also

- The Windows installer offers Japanese and Korean too, on the same terms as Chinese: used
  when the compiler has the language file, English when it does not.
- The plain-text report pads by display width, so Japanese and Korean tables line up like the
  Chinese ones already did.
