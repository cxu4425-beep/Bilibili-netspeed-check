## 中文

這一版把 LagScope 從「告訴你延遲多少」變成「**告訴你該怪誰、該怎麼辦**」。

### 🩺 網路體檢：分段診斷

延遲 180ms 之後，真正的問題是**哪一段慢**。體檢把整條路徑拆開量：

```
你 → 路由器:      38 ms   丟包 0%   (192.168.1.1)
路由器 → 電信商:  44 ms   丟包 0%   (100.64.0.1)
→ 目標伺服器:     71 ms   丟包 0%   (8.8.8.8)
Wi-Fi: 家裡的路由器  41%  802.11n

延遲主要卡在你和路由器之間，而且 Wi-Fi 訊號偏弱——靠近路由器或改用網線會明顯改善。
```

結論分成五種，每種都對應一個可以動手的方向：

| 結論 | 你能做什麼 |
| --- | --- |
| **Wi-Fi** | 靠近路由器、換 5GHz、改用網線 |
| **家裡網路** | 路由器過載？重開機？換網線？ |
| **電信商** | 你改不了——拿這份報告去問客服 |
| **伺服器** | 換伺服器／節點最有效 |
| **丟包** | 比延遲更傷遊戲和通話，優先處理 |

**新增了封包遺失率量測**（之前完全沒有，但遊戲卡頓往往是丟包不是延遲），
以及 **Wi-Fi 訊號強度**（很多「延遲高」其實是訊號問題）。

用法：托盤選單 → **網路體檢…**，或 `LagScope.exe --diagnose`（可指定目標 `--diagnose 8.8.8.8`）。

全部使用系統內建工具（`ping`、`tracert`/`traceroute`、`netsh`/`iw`），**不需要管理員權限**。
統計值是從每一筆回應自己算的，不解析會被翻譯的摘要行，所以中文版 Windows、英文版、
Linux、macOS 都一樣準（四種輸出格式都有測試涵蓋）。

### 👀 同時監測多個對象

主要對象之外，還能再掛最多 **4 個附加監測**：

```
延遲          16 ms
連線數            5
顯示          33 ms
────────────────────
路由器         2 ms    ← 綠
DNS 8.8.8.8   28 ms    ← 綠
Discord 語音 180 ms    ← 紅
公司 VPN         --
```

一眼分辨「**只有這個卡**」還是「**整條線都卡**」——這種判斷用單一數字做不到。

- 設定 → 常規 → **同時監測（附加）**，有 **＋路由器**（自動偵測閘道）與 **＋DNS** 快捷鍵
- 附加目標**輪流**量測（每輪一個），所以加幾個都不會拖慢主要數字
- 懸浮窗和手機儀表板都會顯示

## English

This release turns LagScope from something that reports latency into something that tells you
**what to do about it**.

### Network check: which segment is to blame

The path is split into **you → router → ISP → server**, each segment measured for latency *and*
packet loss, with the Wi-Fi signal read alongside. The verdict names the culprit - weak Wi-Fi,
the home network, the provider, the distance to the server, or loss - and each one points at a
different action. Packet loss is measured for the first time here; for games it matters more
than latency does.

From the tray menu, or `LagScope --diagnose [host]`. It uses only tools that ship with the OS,
needs no administrator rights, and computes its statistics from the individual replies, so it
reads identically in any system language.

### Watch several targets at once

Up to four side watches (router, DNS, a voice app, any address) sit under the main figure with
their own colour bands, on the overlay and on the phone dashboard. That is what separates "only
this game is laggy" from "the whole line is". They are measured one per round, in turn, so
adding them never slows the main figure down. Quick-add buttons fill in your router and DNS.

### Also

Probe errors are now localised, and a machine with no `ping` says so rather than reporting the
target as unreachable.

### Still to come

A history window and a one-click exportable report.
