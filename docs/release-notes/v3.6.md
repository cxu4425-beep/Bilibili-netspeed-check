## 中文

### 📥 Windows 安裝程式

Releases 多了一個 **`LagScope-setup.exe`**：雙擊、下一步，就會建立開始功能表捷徑、
可選桌面捷徑和開機自動啟動，解除安裝也乾淨。

- **不需要系統管理員權限**——裝在你自己的使用者資料夾裡，所以公司、學校的電腦也能裝，
  不會跳 UAC。
- 解除安裝時會**問你要不要保留設定和延遲歷史**，而不是默默刪掉幾個月的紀錄，也不是默默留下垃圾。
- 想要免安裝的還是有：`LagScope-windows-x64.zip` 解壓縮就能跑，適合放隨身碟。

### 🧭 初次設定精靈

第一次打開不再是「五個分頁的設定視窗」，而是三個問題：

![初次設定](https://raw.githubusercontent.com/cxu4425-beep/LagScope/v3.6/docs/images/wizard.png)

① 要監測什麼（自動跟隨 B 站／某個程式／某個位址／先只看網路）
② 懸浮窗放哪裡
③ 要不要檢查更新

回答完就開始跑，其它全部保持合理預設。已經在用的人不會看到它。

### 🔄 更新提醒

每天最多一次向 GitHub 查「最新版本號是多少」，就是讀一個公開頁面。

- **不上傳任何資訊、不含識別碼、不會自動下載或安裝。**
- 發現新版時是**托盤氣泡＋選單項目**，不是彈跳視窗——這程式常常在全螢幕遊戲後面跑，
  不該搶你的焦點。
- 可以「跳過這個版本」，也可以在精靈或設定裡整個關掉。托盤選單的「檢查更新…」是手動查一次。

README 也新增了一張表，列出這程式總共會連的四個地方，除此之外沒有了。

### 🔍 卡頓時自動查原因

走勢圖底部的紅線告訴你「這時候卡過」，但不會告訴你為什麼——除非當時剛好有人在電腦前按體檢。

現在只要偵測到卡頓或延遲突增，就會在背景自動跑一次**精簡版分段診斷**
（3 個 ping、約 2 秒、不跑 traceroute），把結論記在那一分鐘上。事後打開報告會多一段：

```
卡頓時發生了什麼
  08-28 21:14   延遲主要卡在你和路由器之間，而且 Wi-Fi 訊號偏弱……
  08-28 23:02   你家網路正常，延遲是從電信商那一段開始變大的……
```

同一個問題最多每 10 分鐘查一次，整晚不穩也不會變成幾百次 ping。設定 → 高級可關。

### 🌐 診斷加上「網域解析」

分段診斷多了一段：**DNS 解析花多久**。這是最常被漏掉的一段——每個 ping 都正常、
網頁就是慢半拍，通常就是它。超過 300 ms 會給出新的結論「換一組 DNS 試試」。
位址型目標（像 `8.8.8.8`）不需要解析，會顯示 0。

## English

### A Windows installer

`LagScope-setup.exe` joins the release: Start menu entry, optional desktop shortcut and
autostart, clean uninstall. It needs **no administrator rights** - everything goes in the
user's own profile, so a locked-down work or school machine can still install it, with no UAC
prompt. Uninstalling *asks* whether to keep your settings and recorded history rather than
deciding for you. The portable zip is still there for a USB stick.

### A three-question first run

A fresh install no longer opens a five-tab settings dialog. It asks what to watch, where the
overlay goes, and whether it may check for updates - then starts. Existing installs never see
it.

### Update notice

At most once a day it asks GitHub what the newest version number is: one public page, no
identifier, nothing uploaded, nothing downloaded or installed automatically. A new version
arrives as a **tray balloon and a menu entry, never a modal dialog** - this thing runs behind
fullscreen games and has no business stealing focus. It can be skipped per-version or turned
off entirely. The README now lists every host the app talks to; there are four.

### It finds out why, on its own

A red tick on the chart says it broke; it never said why, unless somebody happened to be at
the keyboard to run a check. Now a stall or a spike triggers a cut-down path check in the
background - three pings, about two seconds, no traceroute - and the verdict is filed against
that minute. The report gains a *What happened when it broke* section listing the times and
the causes. At most one check every ten minutes, so a rough evening is not hundreds of pings.

### Name lookups are part of the diagnosis

The path check now also times DNS resolution - the segment that goes missing when every ping
is healthy and pages still feel slow. Over 300 ms it says so, and suggests trying a different
resolver. An address needs no lookup and reports 0.

### Also

- The README leads with an animated overlay: latency climbs, the figure turns red, it
  recovers - while the router and DNS watches beside it stay green throughout.
